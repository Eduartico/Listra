Relist

Relisting backs the listing up first, then — for a listing that is still live — deletes it and recreates it from that backup with the same photos. The delete comes first because Vinted rejects a new listing whose photos match a live one. Sold listings are simply recreated. One at a time, with a pause between each, because creating listings is what Vinted watches most closely.
